## 高度在哪裡設定
- L10：系統與專案 → 該設備的「更多操作」→「升 L11」→ 選專案與實際 U 高度。
- L11：設備的「更多操作」→「修正高度」，或單機詳情右側、Rack 的「機櫃位置」視窗。
- 轉成 L11 不自動找空位。實際上櫃時仍需選擇可容納整台設備的 U 位。
- 已上櫃的一般設備保留上緣 U 位；櫃內 CDU 保持底部 U1。衝突時先移位或移出機櫃，再修正高度。
- 空白專案也可作為首次升 L11 的目標；純 L10 專案不接受直接混入。
