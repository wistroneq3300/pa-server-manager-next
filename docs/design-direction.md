# Wistron UI 設計方向與預覽
日期：2026-09-26。階段：設計提案／待使用者檢視，尚未授權正式實作。

## 已確認的設計原則
- 2026-09-28 使用者指定首頁主標題為「系統架構總覽」。產品仍為 Wistron PA Server Manager，涵蓋有 GPU 與無 GPU 的設備／專案，不以 GPU 限縮全站定位。
- 沿用既有 Wistron 品牌識別與藍／綠方向，保留深色與淺色主題。
- 主要操作按鈕、目前選取項目、警告狀態必須呈現明確且不同的視覺層級。
- 統一 Ping 可達、Ping 未回應、尚未觀測的文字、圖示與狀態色。
- 驗證深淺色主題的文字與背景對比；一般文字、placeholder 目標至少 4.5:1，大字至少 3:1。
- 降低低優先資訊的亮藍綠色使用量，讓待處理項目更突出。
- 保留原有 3D 設備材質、機櫃與工程模型特色。香檳面板、金屬灰、石墨設備、CDU 材質，以及管線／水流的工程意義都應保留。
- 本專案以現有官方標誌資產與既有配色為設計依據，尚未取得完整 Wistron CI 色票與應用規範；不得聲稱已通過官方 CI 認證。原有香檳／金屬材質屬於模型設計，不代表官方品牌色。

## 已納入的 UI 增強方向
1. 加強首頁異常設備處理流程：由異常總數直達完整待確認清單，支援搜尋、篩選與進入設備詳情。
2. 讓 Rack Manager 更容易操作：突出目前專案／設備、整理配置與連線檢查入口，將電源操作維持獨立分組，保留 3D 與精確 U 位工作流。
3. 增加更清楚的狀態顏色和圖例，避免只以紅綠色傳遞資訊。
4. 加強 Wistron 品牌感，同時延續既有 3D 工程風格。
這些是同意探索的設計方向，並不等於授權把原型全部套入正式應用。

## 第一版設計提案
| 用途 | 深色方案 | 淺色方案 | 語意 |
|---|---|---|---|
| 主要操作 | #006C93 / 白字 | #006C93 / 白字 | 執行目前主要工作 |
| 目前選取 | #153F51 / #B8E6F8 | #E0EEF3 / #005875 | 目前位置或篩選，非成功狀態 |
| Ping 可達 | #20392B / #B6DFA0 | #E7F1DF / #345A22 | ICMP 收到回應，附勾選圖示 |
| Ping 未回應 | #422C30 / #FFB4AE | #FAE9E6 / #9A302B | ICMP 未回應，附警示圖示；不直接判定硬體故障 |
| 尚未觀測 | #293B46 / #C1CDD4 | #E8EEF1 / #485B66 | 無觀測結果，附中性圖示 |
| 警告／高影響操作提示 | #413525 / #F3CC87 | #FBEFDB / #785016 | 需要留意的操作；與 Ping 失敗分開 |
| 次要文字 | #ADBEC7 | #4C6470 | 說明及背景資訊，不與主要行動搶注意 |

色值為可供討論的 UI 提案值，不是新訂官方 Wistron 色票。未設定 IP 應顯示「未設定」，避免與已設定但未觀測混淆；零筆異常不代表硬體健康已確認。

首頁沿用原有導航與 3D 展示，在上方呈現緊湊摘要、完整待確認清單、OS／BMC 分欄狀態、搜尋／篩選與 Rack 入口。Rack 沿用原有 WebGL 模型、設備檢視器和配置，整理上方操作區，增加一致的 Ping 圖例。

## 預覽方式與隔離範圍
- 這是一份可操作的設計原型，不是正式程式實作或部署。
- 預覽入口：http://127.0.0.1:8886/ 。頁首可切換「原版／設計提案」、「首頁／Rack」及深淺色。
- 可攜式預覽已納入 repository 的 [docs/design-preview/](design-preview/README.md)，由 server.py 注入 proposal.css / proposal.js；本次交付目錄 outputs/design-preview/ 保留原始交付副本。
- 預覽讀取現有 static 資產，注入原有 preview-fixtures.js；設備與請求由示範資料處理。server.py 僅提供 static 與設計檔，其他 API／WebSocket 路徑不連接正式服務。
- 正式 static/index.html、JS、CSS、模型、資料庫與庫存檔均未套入提案。
- 啟動方式：在 repository 根目錄執行 `python docs/design-preview/server.py --port 8886`；程式會自動使用同一 checkout 的 static 資產。若單獨搬移預覽，可用 --repo 指定這份專案的位置。
- 原型的比較工具列會同時存在於原版與提案中；「原版」表示使用原有應用渲染與樣式，不含提案層。

## 後續工作規則
本版已在瀏覽器抽查首頁與 Rack、原版／提案切換、深淺色、搜尋、無結果／空清單及進入設備詳情。實際窄視窗寬度約 394 CSS px，首頁整頁未橫向溢出，表格保持區域橫向捲動。主要按鈕文字對比 5.89:1；三種 Ping 標籤在深色約 7.16–8.36:1、淺色約 6.05–6.86:1；選取狀態、說明文字與搜尋文字的抽查也高於 4.5:1。這只驗證提案中的代表性組件，並非全站對比或無障礙認證。

JavaScript 語法檢查通過；提案 JS 的 Impeccable 靜態掃描未回報項目（未涵蓋完整渲染／CSS 的認證）。正式 static 程式碼維持不變。2026-09-28 使用者要求將設計文件與獨立預覽一起提交、推送，供後續 review 使用；這不代表正式套用或部署。
